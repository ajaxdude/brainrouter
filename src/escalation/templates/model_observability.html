Definitions, debounce and missing data

Only successfully completed, uniquely correlated streams enter performance samples. Missing usage does not become zero throughput. Both windows must meet the minimum sample count for each metric independently. Repeated polling does not advance debounce or recovery. A no-data state is not recovery.

Fallback counts indicate the model served a fallback route, not that it caused the fallback. Error categories use explicit router error text only; they do not diagnose thermal throttling or memory pressure. Stream failures are excluded from performance samples but may not be recorded as router errors.
